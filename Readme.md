# Provisioning
To provision follow these steps:
- Add public key to root account on server (found in `deploy.php`)
- Run ` vendor/bin/dep provision`

# Deployment
To deploy follow these steps:
- Add public key to root account on server (found in `deploy.php`)
- Run ` vendor/bin/dep deploy`
